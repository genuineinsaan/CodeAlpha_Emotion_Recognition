Emotion Recognition from Speech

Deep Learning Based Speech Emotion Analysis System

About This Project

This application uses Deep Learning and Speech Processing techniques to identify emotions from human voice recordings. The model can classify Happy, Sad, Angry, Fearful, Calm, Neutral, Disgust and Surprised emotions.

## 🚀 Project Overview

Emotion Recognition from Speech is a Deep Learning-based web application that predicts human emotions from voice recordings.

The system extracts MFCC audio features, processes them through a trained TensorFlow neural network, and predicts emotions in real time through an interactive Flask web interface.

Users can either:

- 📁 Upload an audio file
- 🎤 Record voice live from the browser
- 📊 View confidence scores
- 🔊 Play uploaded audio
- 🤖 Receive AI-based emotion predictions
